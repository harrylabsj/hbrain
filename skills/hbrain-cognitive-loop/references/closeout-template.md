# Hbrain Cognitive Loop Closeout Template

Use this for deep conversations, second-brain design, durable judgments, and any user-requested writeback.

```text
本轮召回（不等于锚点训练事件）：
- [[concepts/...]] / [[entities/...]] / [[queries/...]]

核心判断：
-

A. 知识沉淀：
- 目标层：
- 建议文件：
- 写回方式：直接低风险记录 / inbox proposal / 需要人工确认

B. 锚点训练：
- 是否有人脑面信号：无 / router miss / recall-check / 人脑显式提名
- 是否需要记录 anchor-event：

人脑必须记住的一句话（只有用户明确要内化时填写）：

下次继续追问：

第二大脑回路：
- 模式：quick / recall / deep
- 锚点：
- 召回：
- 写回：
```

Low-risk writes:

- Writeback proposal markdown.
- Automation report.
- Human-side anchor-event JSONL only for recall-check, human-source router miss, or explicit human nomination.

Do not record AI material usage, route hits for agent convenience, or knowledge deposition itself as anchor-events. Do not directly rewrite durable wiki pages unless the user explicitly requests it.
